# Repository language

Use English for repository content, including documentation, code comments, and commit messages.

# Commits

After completing a requested change in this repository, create a local Git commit for the task's changes and include its short hash in the reply. A later request can override this default.

# Development Instructions

Before modifying RTL, read:
1. docs/PRODUCT_SPEC.md
2. The current milestone requirements

Treat PRODUCT_SPEC.md as the authoritative
definition of the final product.

Do not replace required programmability with
hardcoded application-specific behavior.

Every implementation must preserve progress
toward user-programmable P1–P5.

Before completing a milestone, report:
- Requirements satisfied
- Newly programmable behaviors
- Remaining hardcoded limitations
- Verification evidence
- Area and timing impact

Do not weaken the Product Specification to
make an implementation appear successful.
